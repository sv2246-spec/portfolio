## Website Link

## Viewing the site

1. Clone or download the repository: Click the green Code button on the GitHub repository page, copy the URL, and clone it via Git Bash/Terminal using git clone <URL> (or just download it as a ZIP file and extract it).
2. Locate the main index.html file in your local folder
3. Double-click index.html (or right-click and choose Open With) to launch it instantly from your web browser.
